# AI and Automation in Laboratory Medicine: Activities

Interactive activities for pre-professional students. Hosted with GitHub Pages.

Home page: https://carthron.github.io/lab-ai-games/

| Activity | Format | Link |
|---|---|---|
| Lab AI Rounds (intro) | Individual, 15–20 min, certificate | https://carthron.github.io/lab-ai-games/games/lab-ai-rounds/ |
| Who Does It? | Teams of 4, about 20 min | https://carthron.github.io/lab-ai-games/games/who-does-it/ |
| Train the AI | Teams of 4, about 20 min | https://carthron.github.io/lab-ai-games/games/train-the-ai/ |
| Lab AI Rounds (advanced) | Individual; not linked from the home page | https://carthron.github.io/lab-ai-games/games/lab-ai-rounds-advanced/ |

## Folder structure

```
index.html                         home page students open
games/<activity-name>/index.html   one folder per activity
```

To update an activity, replace that folder's `index.html`. To add one, create a new folder under `games/` and add a card to the home page.

Student answers stay in each student's browser. Nothing is collected or sent.
